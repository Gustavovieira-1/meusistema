Uso de Dados do Google

Última atualização: 2 de setembro de 2026

Esta página explica como a Zira usa serviços e dados relacionados ao Google, inclusive para atender à Google API Services User Data Policy e à regra de Limited Use, quando aplicável.

1. Serviços Google que podemos usar

  • Google Fonts: para carregar tipografia no site e no sistema. O Google pode receber o IP do visitante ao baixar a fonte.
  • Google Ads / tags (se ativados): medição de campanhas e conversões.
  • APIs de conta Google (se o usuário conectar login ou outro recurso Google no futuro): apenas os dados necessários para o recurso solicitado.
  • Menção a Google Meu Negócio no material de divulgação refere-se a canal de divulgação do restaurante, não a acesso automático à conta Google do usuário.

2. O que fazemos com dados do Google

Quando um usuário autoriza a Zira a acessar dados via APIs do Google, nós:

  • Usamos esses dados somente para fornecer ou melhorar o recurso que o usuário pediu.
  • Não vendemos dados do Google.
  • Não usamos esses dados para anúncios independentes, inclusive remarketing, de públicos semelhantes ou publicidade personalizada.
  • Não transferimos os dados a terceiros, salvo para prestar o serviço (infraestrutura), cumprir a lei ou se o usuário autorizar.
  • Humanos só acessam esses dados com consentimento do usuário, para segurança, cumprimento legal ou quando o dado foi tornado público pelo próprio usuário.

3. Limited Use

O uso de informações recebidas das APIs do Google adere à política de Dados de Usuário dos Serviços de API do Google, inclusive os requisitos de Limited Use. Não utilizamos esses dados para treinar modelos de IA generalizados nem para finalidades não relacionadas ao produto que o usuário habilitou.

4. Armazenamento e exclusão

Tokens e dados obtidos do Google, quando existirem, ficam armazenados o tempo necessário para o recurso funcionar. O usuário pode desconectar a integração e pedir a exclusão conforme a página de exclusão de conta e dados.

5. Revogação no Google

Além do pedido à Zira, o usuário pode revogar o acesso da Zira em myaccount.google.com/permissions.
